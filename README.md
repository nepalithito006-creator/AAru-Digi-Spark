# Aaru Digi Spark — Cream Anime Website

A responsive, single-file HTML website for Aaru Digi Spark, featuring a warm cream palette, anime-inspired illustration, floating sakura decorations, gentle glow and sparkle animations, service detail routes, portfolio concepts, and a contact form that opens an email draft.

## Publish on GitHub Pages

1. Download and extract this ZIP.
2. Open your GitHub repository: `nepalithito006-creator/AAru-Digi-Spark`.
3. Upload `index.html` to the repository root, replacing the old `index.html` when prompted. Keep `README.md` if you want.
4. Commit the changes.
5. In **Settings → Pages**, make sure deployment is enabled for the `main` branch and `/ (root)`.
6. Open your published GitHub Pages website after deployment finishes.

## Contact form

The form creates a draft email using the visitor's email app. In `index.html`, find `const recipient=''` near the bottom and replace the empty quotes with your receiving email address, for example `const recipient='you@example.com'`.

No build tools or packages are required. The site is plain HTML, CSS, and JavaScript.
