Aaru Digi Spark website

GitHub Pages upload instructions:
1. Extract this ZIP file.
2. Open your GitHub repository: nepalithito006-creator/AAru-Digi-Spark
3. Click Add file > Upload files.
4. Upload index.html (and optionally this README.txt) to the repository root.
5. Commit the changes.
6. In Settings > Pages, ensure deployment is enabled from the main branch and /(root).
7. Open your GitHub Pages URL after deployment finishes.

Note: The contact form currently prepares an email draft. To receive inquiries, edit index.html and set the recipient variable near the bottom of the script to your real email address.
