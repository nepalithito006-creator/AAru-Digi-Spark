UPLOAD TO GITHUB PAGES
1. Extract this ZIP.
2. Open your GitHub repository: https://github.com/nepalithito006-creator/AAru-Digi-Spark
3. Upload every .html file to the repository root (same level as index.html).
4. Commit the changes. Keep the filenames exactly as shown.
5. Open Settings > Pages and ensure the source is the main branch and /(root).
6. Visit: https://nepalithito006-creator.github.io/AAru-Digi-Spark/

CONTACT FORM
The contact form opens an email draft. In contact.html, find const recipient='' and put your email between the quotes, for example const recipient='you@example.com'. The email app must be configured on the visitor's device. For a server-backed form, a separate form service is needed.

All pages are responsive and share the same purple anime-inspired design.
